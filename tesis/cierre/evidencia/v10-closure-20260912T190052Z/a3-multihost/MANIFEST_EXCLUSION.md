# Manifest exclusion (historical)

This directory held the working runbook, scripts and outputs of the manual two-host A-3 exercise while it was in
progress, and was excluded from `../SHA256SUMS` for that reason.

**Update (closure, 2026-09-12): the exercise is finished and this exclusion no longer applies.** This directory
now has its own `SHA256SUMS` (see `README.md`, "Cómo verificar el paquete"), and the parent manifest
(`../SHA256SUMS`) was regenerated to include it. This file is kept for history instead of being deleted.
